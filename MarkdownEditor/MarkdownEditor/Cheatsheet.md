# Markdown Syntax

## Headings

# H1
## H2
### H3

## Emphasis

*Italic* or _italic_

**Bold** or __bold__

**_Bold and italic_**

~~Strikethrough~~

## Lists

### Ordered

1. First item
2. Second item
3. Third item

### Unordered

- First item
- Second item
   - Nested item

### Task list

- [x] Completed task
- [ ] Incomplete task

## Links and images

[Link text](https://www.example.com)

![Alt text](https://www.example.com/image.png)

## Blockquotes

> A single-line blockquote.

> A multi-line blockquote.
>
> Still part of the same quote.

## Code

Inline `code` uses backticks.

```
A fenced code block.
No syntax highlighting required.
```
